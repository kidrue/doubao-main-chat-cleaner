# 豆包主对话批量删除

在豆包网页版的开发者工具 Console 中运行，分批清理当前主对话内的消息。支持串行删除、停止、运行状态查询，以及复选框和页面状态的只读诊断。

**粘贴主脚本并回车后会立即开始实际删除，已提交的删除无法撤回。**

使用方法、参数和注意事项见 [使用说明.md](使用说明.md)。

- `豆包主对话批量删除.js`：主脚本。
- `复选框只读诊断.js`：排查勾选状态。
- `页面状态只读诊断.js`：排查页面结构和超时状态。
- `.verification/`：本地浏览器验证代码及依赖清单。

本地验证使用 Node.js 和 Google Chrome；测试中的 Chrome 路径为 Windows 默认安装路径：

```powershell
npm --prefix .verification ci
node --test .verification/delete.test.cjs
```

完整测试还依赖项目根目录中的四份本地页面快照：`默认.txt`、`点击了会话的扩展按钮.txt`、`点击了删除选项.txt`、`删除确认框.txt`。这些文件可能包含聊天内容，未上传至仓库；运行完整测试前需自行准备对应快照。现有测试在本地页面和组件中验证，不会连接豆包在线页面执行删除。
